# 📱 App Medidores - Campo

App simple para registrar medidores en campo con fotos.

## ✨ Características

- ✅ Digita número de medidor
- ✅ Digita nombre del local
- ✅ Agrega observación
- ✅ Toma fotos desde el celular
- ✅ Descarga Excel con los registros

## 🚀 Cómo usar

1. Abre el link desde tu celular
2. Digita los datos del medidor
3. Toma fotos
4. Guarda el registro
5. Descarga el Excel cuando termines

## 📦 Dependencias

- streamlit
- pandas
- openpyxl
- pillow
